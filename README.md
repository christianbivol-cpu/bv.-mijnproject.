# Cluster 1 
  
Django-project van 6ECWI, GO! atheneum Anne Frank Denderleeuw. 
  
## Het project opstarten 
  
1. Clone de repo met GitHub Desktop. 
2. Open de map in VS Code en open een terminal. 
3. Maak een virtuele omgeving: 
   - Windows: `py -m venv .venv` en `.venv\Scripts\Activate.ps1` 
   - Mac: `python3 -m venv .venv` en `source .venv/bin/activate` 
4. `python -m pip install -r requirements.txt` 
5. `python manage.py migrate` 
6. `python manage.py runserver` en open http://127.0.0.1:8000
